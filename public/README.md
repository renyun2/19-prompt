# 测试页面使用指南

## 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动测试服务器
```bash
npm run start:test
```

服务器将在以下地址启动：
- HTTP: http://localhost:3000
- WebSocket: ws://localhost:3000

### 3. 打开浏览器
访问: http://localhost:3000

## 功能说明

### 连接配置
- **WebSocket地址**: ws://localhost:3000（默认）
- **用户ID**: 自定义用户标识（如 user001）
- **Token**: 认证token（任意非空字符串）

### 主要功能

#### 1. 连接管理
- 点击"连接"按钮建立WebSocket连接
- 点击"断开"按钮关闭连接
- 实时显示连接状态

#### 2. 消息功能
- 发送文本消息
- 接收实时消息
- 消息历史记录
- 消息时间戳

#### 3. 会话管理
- 创建私聊会话
- 会话列表显示
- 切换会话
- 会话消息加载

#### 4. 快速操作
- **创建测试会话**: 自动创建一个随机用户的会话
- **发送测试消息**: 自动发送随机测试消息
- **清空日志**: 清除系统日志记录

### 统计数据
实时显示：
- 消息总数
- 会话总数
- 在线用户数

## 多窗口测试

可以在多个浏览器窗口或标签页中打开测试页面，模拟多用户聊天：

1. 打开第一个窗口，使用用户 user001 连接
2. 打开第二个窗口，使用用户 user002 连接
3. 在任一窗口发送消息，另一窗口会实时接收

## WebSocket 服务器

测试服务器提供以下功能：

### 支持的消息类型
- `auth:login` - 用户认证
- `message:send` - 发送消息
- `ping/pong` - 心跳检测
- `user:status:update` - 更新用户状态

### 服务器响应
- `auth:login:success` - 认证成功
- `message:sent:ack` - 消息发送确认
- `message:received` - 接收消息
- `user:connected` - 用户上线
- `user:disconnected` - 用户下线
- `user:status:changed` - 用户状态变更

## 调试技巧

### 1. 查看系统日志
页面底部的"系统日志"区域会显示所有操作和事件

### 2. 浏览器开发者工具
- F12 打开开发者工具
- Network标签查看WebSocket连接
- Console标签查看JavaScript错误

### 3. 服务器日志
启动测试服务器后，终端会显示：
- 客户端连接/断开
- 消息收发记录
- 认证信息
- 错误信息

## 常见问题

### 1. 连接失败
- 确认测试服务器已启动
- 检查WebSocket地址是否正确
- 查看浏览器控制台错误信息

### 2. 消息发送失败
- 确认已成功连接
- 确认已创建会话
- 检查消息内容是否为空

### 3. 收不到消息
- 确认WebSocket连接状态
- 检查服务器日志
- 尝试刷新页面重新连接

## 技术栈

### 前端
- 纯HTML + CSS + JavaScript
- 原生WebSocket API
- 响应式设计

### 后端
- Node.js
- ws（WebSocket库）
- HTTP静态文件服务

## 自定义扩展

### 修改服务器端口
编辑 `server/test-server.js`:
```javascript
const PORT = process.env.PORT || 3000;
```

### 添加新的消息类型
在 `server/test-server.js` 的 `handleMessage` 函数中添加新的 case

### 自定义界面样式
修改 `public/index.html` 中的 `<style>` 部分

## 注意事项

⚠️ 此测试服务器仅用于开发和测试，不适合生产环境使用。

生产环境需要：
- 完整的用户认证系统
- 数据库持久化
- 消息加密
- 负载均衡
- 错误恢复机制
- 日志记录系统
